# BULBENI Design System

## Design character

BULBENI should feel human, editorial, academic, sophisticated, professional, warm, premium, and approachable. It must not resemble a generic AI-generated SaaS dashboard.

Avoid purple AI gradients, glassmorphism, excessive gradients or pills, excessive floating cards, neon/glowing effects, clutter, and unnecessary animation.

## Colors

Use the approved direction:

- Warm ivory/off-white backgrounds
- Deep ink/navy primary text and navigation
- Muted sage/eucalyptus accents
- Restrained teal where useful
- Warm ochre/terracotta secondary accents
- Warm light-gray borders

Do not introduce unrelated primary colors without a clear product reason.

## Typography

Use a refined serif for prominent editorial headings where appropriate and a clean sans-serif for interface text.

| Role | Preferred size |
| --- | --- |
| Profile/main names | 28–32px |
| Major headings | 18–20px |
| Card headings | 16–18px |
| Body text | 14–16px |
| Metadata | At least 12–13px |
| Sidebar labels | 15–16px |
| Buttons | 14–16px |
| Chips/tags | 12–14px |

Avoid tiny interface text. Maintain comfortable, proportional line heights.

## Layout

- Use CSS Grid for complex dashboard compositions.
- Preserve intentional side-by-side desktop sections.
- Do not accidentally stack desktop cards vertically.
- Collapse grids deliberately for tablet and mobile.
- Keep a sensible maximum content width on very wide screens.
- Maintain whitespace, alignment, and clear hierarchy.

## Cards

- Use moderate corner radii.
- Use subtle borders and very subtle shadows.
- Favor structured sections over excessive floating surfaces.
- Do not place every individual fact in its own card.

## Motion

Allowed motion includes subtle fades, small translations, hover refinement, animated progress, smooth drawers/modals, and elegant toast entrances.

Avoid bouncing, spinning, exaggerated scaling, and unnecessary continuous animation. Respect reduced-motion preferences.

## Decorative imagery

Education PNG assets currently live under `public/` (not `public/assets/` in the current repository). Available examples include books, an open book, graduation cap, diploma, stationery, and school imagery.

Use these sparingly as professional supporting decoration, not primary content. Avoid childish or cluttered compositions.
