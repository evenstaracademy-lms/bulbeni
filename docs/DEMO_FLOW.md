# BULBENI Demo Flow

## Teacher demonstration

1. Open the BULBENI homepage.
2. Enter the teacher experience.
3. Open the teacher dashboard.
4. Reset the demo profile if a known starting state is needed.
5. Show the intentionally incomplete profile, current percentage, and checklist.
6. Open **Edit Profile**.
7. Add or change the profile image and show the immediate preview and percentage change.
8. Add certificate details.
9. Upload certificate evidence.
10. Show the **Pending verification** state and changed completion percentage.
11. Optionally add an introduction-video URL and explain its completion weight.
12. Save the profile and show the success toast.
13. Return to the dashboard and confirm the percentage persists.
14. Open **My Profile** and show the completed professional presentation.
15. Demonstrate **View as School** as a prototype interaction.
16. Browse the school directory when that route is implemented.

The flow should prove that this is an interactive application rather than a static mockup.

## School demonstration

The current school route is visual-only. Once its Phase 1 directory interactions exist:

1. Enter the school experience.
2. Show the teacher directory.
3. Search and filter teachers.
4. Explain rule-based recommendation percentages.
5. Save a teacher.
6. Open a complete teacher profile.
7. Demonstrate locked contact details.
